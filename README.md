# テーブルタワーディフェンス

**AR技術を活用し、身近なテーブルを戦場に変えるタワーディフェンスゲーム**

<!-- [ここにステージ設置後の実際のスクリーンショットを掲載] -->

## 1. 作品概要

テーブルタワーディフェンスは、スマートフォンのAR機能を活用し、現実のテーブル上にゲームステージを展開するタワーディフェンスゲームです。

スマートフォンを持ち寄ることで、同じ場所に集まった人たちが対面でゲームを楽しめる体験を目指しています。

## 2. 企画意図

### 対面で遊ぶ楽しさを、もう一度身近に

インターネットを通じて離れた人とも遊べるようになった一方で、友人の家に集まり、ゲーム機を持ち寄って一緒に遊ぶ体験にも魅力があると考えています。

本作では、スマートフォンの持ち運びやすさを活かし、教室やリビング、旅行先など、身近な場所で気軽に遊べるゲームを目指しています。

### なぜスマートフォンなのか

スマートフォンは多くの人が普段から持ち歩いており、複数人で集まる際にも持ち寄りやすいデバイスです。

専用のゲーム機や大型の機材を必要とせず、遊びたい場所に集まってゲームを始められることを重視しました。

### なぜARなのか

ARを活用することで、現実のテーブルをゲームの舞台として利用できます。

従来の画面内だけで完結するゲームとは異なる体験を生み出し、対面ならではの遊び方を提案したいと考えています。

また、タワーディフェンスというジャンルを採用することで、複数人で戦況を見ながらコミュニケーションを取る楽しさを取り入れたいと考えています。

## 3. 技術構成と実装状況

現段階では、各機能をゲーム全体として統合することが今後の課題です。

### 使用技術

- **AR Foundation / ARCore**：現実空間の認識とAR表示

## 4. 技術課題と解決へのアプローチ

### 課題1：平面検出の精度と安定性

**問題**

ARの平面検出は、認識にかかる時間や検出精度が環境によって変化します。そのため、安定してゲームステージを生成することが課題となっています。

**解決へのアプローチ**

平面検出による位置情報に加え、画像認識を利用してステージの高さを補正する方法を検討しています。

それぞれの機能を組み合わせることで、ステージ配置の安定性を高めることを目指しています。

<!-- ![Images/PlaneDetectionIssue.png](Images/PlaneDetectionIssue.png) -->

### 課題2：複数端末間での座標合わせ

**問題**

各端末が独立してAR空間を認識すると、端末ごとの座標系に違いが生じます。同じステージを共有するには、この違いを考慮する必要があります。

**解決へのアプローチ**

画像マーカーを基準として座標を再構築し、端末間で共通して扱える座標系を確立する方法を検討しています。

<!-- ![Images/CoordinateSystem.png](Images/CoordinateSystem.png) -->

今後は、座標の基準を合わせる処理とネットワーク上の同期処理を組み合わせ、複数端末で同じゲーム空間を扱えるようにする予定です。

### 課題3：敵AIの実装

**問題**

タワーディフェンスとして成立させるには、敵の移動や行動を管理し、ゲームとして適切な戦況を作る必要があります。

**今後の方針**

AR空間の構築と座標管理を安定させた後、敵の移動経路や行動制御を実装し、ゲーム部分との統合を進める予定です。

## 5. 今後の実装計画

今後は、次の順序で開発を進める予定です。

1. AR関連機能の統合と、ステージ配置の安定化
2. 画像マーカーを基準とした座標合わせの検証
3. 敵の移動・行動制御など、タワーディフェンス部分の実装
4. Netcode for GameObjectsを利用した複数端末間の同期
5. 実機での動作検証と、ゲーム全体の調整

各機能を個別に検証したうえで段階的に統合し、最終的には複数人が同じテーブルを囲んで遊べるゲームとして完成させることを目指しています。

## 6. まとめ

本作では、ARによって現実空間をゲームの舞台にするだけでなく、複数端末で同じ空間を共有するための仕組みづくりにも取り組んでいます。

現在はAR関連機能の個別実装と検証を進めており、今後はそれらを統合し、実際に対面で遊べるタワーディフェンスゲームへと発展させていく予定です。
